### 🏛️ Learning Guide for Trainers

* **Badges:** Your core learning materials are marked with the red <span class="badge track-trainer">Trainer</span> label. You will frequently see this combined with the Manager tag on pages discussing group training logistics and timelines.
* **Tabs:** Use the **Trainer** tabs to access presentation advice, icebreaker activities, and evaluation rubrics instead of raw backend data configurations.
* **Seamless Navigation:** You can switch between tracks at any time using the top navigation bar, or use the left sidebar search to find specific exercises or learning outcomes across the whole portal.
